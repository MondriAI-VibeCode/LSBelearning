Cloud-opslag (Firebase Firestore)

Gekoppeld aan project: lessen-opslag

Volgorde aanpassen: Log in via Beheer (`mon1234!`). Je kunt daarna zowel vakken als lestegels slepen met je muis of verplaatsen met de pijltjesknoppen. De volgorde wordt direct in Firebase opgeslagen.

Toegangsrechten (Rules) in Firebase:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
